# 广州公共交通线网（公交 + 地铁）

基于广州公交与地铁开源数据构建的交互式线网网站原型，数据经「车来了」方向分站坐标校验与修正。

## 功能

- 公交 2632 条线路、去重站点 10162 个、BRT 68 条；地铁 42 条运营 / 28 条在建规划记录、车站 409 个；
- 地图叠加：地铁线路（彩色=运营、灰虚线=在建/规划）、地铁车站、公交站点（聚合显示）、公交线路（蓝色=BRT）；
- 线路搜索（527、B1、地铁1号线、110、113…）与站点搜索（拼音/首字母也可，如 ycd→员村东）；
- 点击线路/站点查看详情；站详情显示①②③分站编号与平台列表；地铁站可查 300 米内公交接驳；
- 方向分台：线路两个方向的停靠点按车来了坐标分置对应站台，并自动吸附在线路上；
- 线路状态：疑似停运/调整线路带标记说明；
- 四种底图可切换（高德街道、高德影像、浅色、OpenStreetMap），默认浅色，并记忆上次选择；
- 首屏数据懒加载，移动端适配（底部面板）。

## 使用

- 默认入口：双击 `transit_site/index.html`
- OSM 版（需能访问海外网络）：双击 `transit_site/index_osm.html`（跳转到 `?basemap=osm`）

页面数据在 `transit_site/data/`，已随仓库保存，无需联网（地图底图组件除外）。

## 目录

```
transit_site/        网站本体（入口页 + 样式 + 逻辑 + 数据）
data/                网站数据主版本（与 transit_site/data 同步）
output/network/      分析产物与备份
*.py / *.mjs / *.js  数据解析与维护脚本
```

## 数据口径提示

- 坐标 WGS84，网页加载时自动转换以适配高德底图；
- 站点 ID 为 BV 开头（与高德同源）；车来了①②③为分站编号，用于方向分台判定；
- 方向分台、站名合并、线路状态等口径详见数据维护手册与治理记录。
