# 广州公共交通线网（公交 + 地铁）

基于广州公交与地铁开源数据构建的交互式线网网站原型。

## 功能

- 公交线路 2612 条、去重站点 10143 个；地铁 21 条运营线（约 713 km）与 13 段在建/规划（约 286 km）、车站 409 个；
- 地图叠加：地铁线路（彩色=运营，灰虚线=在建/规划）、地铁车站、公交站点（聚合显示）、公交线路（蓝色=BRT）；
- 线路搜索（如 527、B1、地铁1号线）与站点搜索（如 梅花村、体育西路）；
- 点击线路/站点查看详情；地铁站可查看 300 米内公交接驳；
- 四种底图可切换：高德街道、高德影像、浅色底图、OpenStreetMap（默认高德，国内加载快）。

## 使用

- 默认（高德底图）：双击 `transit_site/index.html`
- OSM 版（需能访问海外网络）：双击 `transit_site/index_osm.html`

页面数据在 `transit_site/data/`，已随仓库保存，无需联网（地图底图组件除外）。

## 目录

```
transit_site/        网站本体（两个入口页 + 样式 + 逻辑 + 数据）
Git使用说明.md        git 新手教程
*.py                 数据解析 / 预处理脚本（可选）
```

## 数据口径提示

- 坐标 WGS84，网页加载时自动转换以适配高德底图；
- 公交站点 ID 不区分上下行，部分站点往返共用同一 ID；
- 地铁数据含在建/规划段，地图上以灰色虚线显示。
